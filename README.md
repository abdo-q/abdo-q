## من أنا؟

أنا **عبدو**، أعمل على مشاريع Android وتطبيقات الويب العربية مفتوحة المصدر. أهتم بإعادة البناء الموثقة، وتحسين واجهات RTL، وتجارب PWA الخفيفة، وجعل التطبيقات الإسلامية أكثر وضوحًا واحترامًا لبيانات المستخدم.
